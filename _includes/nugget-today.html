{% comment %} Today's nugget, surfaced on the homepage. Rendered client-side rather than at build time on purpose: nuggets.json is seeded with future-dated entries, and the app only reveals one once its date arrives (see nugget/app/src/nuggets.ts). A Liquid render would freeze on whichever day GitHub Pages last built the site, so the same date <= today rule is applied in the browser against the app's own JSON. One source of truth, no rebuild needed to advance the day. The section stays hidden unless a nugget is actually available, so a failed fetch or an exhausted feed leaves no empty panel behind. {% endcomment %}
